# Changelog

## 0.1.0

First release. Experimental.

- Symbol and dependency index (JS/TS, Python, GDScript), incremental by file hash.
- `ctx`: ranked symbol capsules under a token budget.
- Verified-knowledge cache with status derived from source file hashes.
- Failure and error memory, developer DNA with an evidence threshold.
- `run`: compressed command output with retrievable raw output.
- Task states, checkpoints, `resume`, loop control, stagnation detection.
- Router, blast radius with predicted-vs-actual comparison.
- Repo scanner for prompt injection and hostile configuration.
- `cost` dashboard from Claude Code transcripts; `bench` harness and report.
- Hooks, 4 agents, 5 skills, 6 commands, 1 rule; `install`, `uninstall`, `doctor`.
